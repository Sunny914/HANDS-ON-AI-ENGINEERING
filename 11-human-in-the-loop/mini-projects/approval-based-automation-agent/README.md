# Approval-Based Automation Agent

A scripted agent proposes actions against fake local tools. Consequential actions pause as pending snapshots. An authorized principal approves, rejects, modifies, or cancels. The executor runs the approved snapshot once, or refuses.

The model never decides that it is allowed. Approval never substitutes for the role check.
