# Acceptance Criteria

- [ ] Dataset version is required and stored on the report
- [ ] Two quality dimensions are scored as different fields
- [ ] At least one case shows a split between those dimensions
- [ ] Baseline and candidate reports exist for the same dataset version
- [ ] A regression names a case id
- [ ] A known failure is not labeled a regression
- [ ] A stub judge cannot clear a rule failure
- [ ] The gate document states a threshold and the sample-size limit
- [ ] Default tests need no API key
- [ ] The checkpoint names one way the lab could be falsely confident
