# Multi-Agent Research and Analysis System

A coordinator and a small set of specialists answer a research question from a local corpus. Specialists are not all used on every task. The system has a single-agent baseline on the same fixtures. You ship the multi-agent path only where the comparison, or a real permission boundary, justifies it.

This is not the Stage 09 agent with extra prompts. The new work is contracts, handoffs, bounded delegation, conflicts, and a recorded decision about overhead.
