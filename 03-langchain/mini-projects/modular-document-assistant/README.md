# Modular LangChain Document Assistant

Summarize a local text file in a structured form. The assistant loads the file, selects an excerpt with a non-vector method, runs a LangChain runnable, and validates the result.

This is not the Stage 04 RAG system. If you add embeddings, you have left the project.

Complete the architecture exercise first. You choose the modules. There is no starter `src/` tree.
