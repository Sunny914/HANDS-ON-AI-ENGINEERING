# AI Execution Observability Toolkit

Instrument one fake AI workflow so a single request id explains the model call, the retrieval, the tool calls, the retries, and the outcome. Then use that trace to name a performance or reliability problem you planted.

The toolkit is not a second copy of the Stage 12 lab. Scores may be absent. Durations, statuses, and redaction must be present.
