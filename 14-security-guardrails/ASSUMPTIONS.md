# Stage 14 Assumptions

- No moderation vendor is required. If you mention one, it is a layer, not the authorizer.
- Secrets in tests use the prefix `sk-test-` and are fake.
- The exercises do not ask you to attack a real system. They ask you to show a local control holding against a string.
- Prompt injection cannot be fully removed by wording. The acceptance criteria never ask you to claim that it is gone.
