# Grade Book CLI (Design)

**ID:** `ex-15`  
**Level:** L4  
**Module path:** `00-python-engineering-reset/exercises/ex-15`

## Objective

Design and implement a small multi-function grade book.

## Prerequisites

- functions
- dicts
- CLI input optional

## Requirements

- Store students → list of scores; support add_score, average, letter_grade (your scale).
- Simple menu loop or command args—your choice.

## Constraints

- At least 3 modules or 3 files

## Expected behavior

- Session usable interactively

## Edge cases

- No scores
- unknown student

## Acceptance criteria

- You can draw module diagram

## Common mistakes

- Global dict everywhere
- No separation of I/O

## H1 hint

Separate storage from presentation from grading rules.

## Files

Create your own `.py` files in this folder unless the exercise provides a starter.
