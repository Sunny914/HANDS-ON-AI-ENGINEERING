# Library Catalog (Basic OOP)

**ID:** `ex-21`  
**Level:** L4  
**Module path:** `00-python-engineering-reset/exercises/ex-21`

## Objective

Model entities with classes.

## Prerequisites

- classes
- methods

## Requirements

- Classes `Book`, `Member`, `Library` with checkout/return rules (max 3 books per member).
- Raise domain errors you define.

## Constraints

- No persistence required

## Expected behavior

- In-memory demo in main

## Edge cases

- Checkout unavailable
- return unknown book

## Acceptance criteria

- At least 2 custom exception types

## Common mistakes

- God class
- Public mutable lists without invariants

## H1 hint

Library orchestrates; Book/Member enforce local rules.
