# Copying Nested Structures

**ID:** `ex-10`  
**Level:** L2  
**Module path:** `00-python-engineering-reset/exercises/ex-10`

## Objective

Shallow vs deep copy behavior.

## Prerequisites

- copy module
- nested lists/dicts

## Requirements

- Given nested dict, functions `shallow_copy_change` and `deep_copy_change` that modify nested value and return copies.
- Explain in comments which original changes.

## Constraints

- Use copy.copy and copy.deepcopy

## Expected behavior

- Demonstration script output documented

## Edge cases

- Immutable nested values

## Acceptance criteria

- Commentary matches behavior

## Common mistakes

- Assuming assignment copies
- Deep copying everything always

## H1 hint

Shallow copy shares nested references.
