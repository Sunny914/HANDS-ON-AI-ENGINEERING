# Module 02 — Async Python Preview

**Bridge to Stage 01** — not a full async/backend course. Six exercises introduce blocking vs concurrency concepts you will extend with FastAPI and HTTP.

## Prerequisites

- Module 00 ex-11+ (exceptions)
- Module 01 ex-10+ (config/logging helpful but not required)
- Comfortable running scripts from CLI

## Exercises

| ID | Title |
|----|-------|
| [ex-01](./exercises/ex-01/README.md) | Blocking sequential work |
| [ex-02](./exercises/ex-02/README.md) | Introducing `async`/`await` |
| [ex-03](./exercises/ex-03/README.md) | Tasks and `asyncio.gather` |
| [ex-04](./exercises/ex-04/README.md) | Timeouts and cancellation intro |
| [ex-05](./exercises/ex-05/README.md) | Sequential vs concurrent comparison |
| [ex-06](./exercises/ex-06/README.md) | Bounded concurrency pattern |

## What you implement

Simulated I/O (sleep, fake network)—**do not** call real external APIs unless you choose to as an extension.

## Exit

[CHECKPOINT.md](../CHECKPOINT.md) Module 02 questions, then proceed to **Stage 01** or finish mini-projects if not already done.

## Note on AI assistance

Implement both sequential and concurrent versions yourself in ex-05/ex-06; compare wall-clock with printed timings.
