# test-01 — Test Requirements (you implement tests)

Implement `mathutils.py`:

- `gcd(a, b)` positive integers
- `lcm(a, b)`
- `clamp(n, low, high)`

## Tests you must write

1. `gcd` of coprime numbers
2. `gcd` where second argument is 0 (define expected behavior in docstring first)
3. `lcm` basic case
4. `clamp` below, inside, above range
5. `clamp` raises when `low > high`

Each test name should describe behavior.
