# Stage 07 Debugging

| Symptom | Look at |
|---------|---------|
| More steps than the budget | The counter or the stop check |
| Same tool forever | No repeat limit, and the script cycles |
| Denied tool still runs | Policy reads the proposal |
| Final answer on a tool error | Stop reason overwritten |
| Test hangs | A `while True` without a ceiling. Add a ceiling before you experiment. |
