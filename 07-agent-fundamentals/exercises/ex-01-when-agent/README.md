# Workflow or Agent

**ID:** `ex-01`
**Stage:** 07-agent-fundamentals
**Difficulty:** L1
**Category:** Conceptual reasoning

## Objective

Refuse an agent when a workflow is enough.

## Prerequisites

CONCEPTS.md opening.

## Problem

Write `CHOICES.md` for three tasks: rename files by a fixed rule, answer from a search whose results change the next query, and send email whenever a model feels confident.

## Requirements

For each task pick workflow, agent, or neither, and name the main failure if you choose wrong.

## Constraints

No code.

## Inputs and outputs

A short note.

## Edge cases

The email task should not become an unbounded agent.

## Errors

Do not say agents are always better.

## Acceptance criteria

The three choices are different where the risks differ, and each names a failure.

## Testing

Read it against the concept page.

## Common mistakes

Choosing an agent because the demo looks modern.
