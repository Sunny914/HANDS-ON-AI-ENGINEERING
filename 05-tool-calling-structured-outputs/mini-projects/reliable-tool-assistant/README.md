# Reliable Tool-Using Assistant

One round-trip assistant for orders: look up an order, and refund it when the principal is allowed. The model proposes a tool. Your code validates, authorizes, executes, and records the result. Tests use fixtures and fakes.

This is not a planner and not a multi-agent system. Complete the architecture exercise before coding. There is no starter source tree.
