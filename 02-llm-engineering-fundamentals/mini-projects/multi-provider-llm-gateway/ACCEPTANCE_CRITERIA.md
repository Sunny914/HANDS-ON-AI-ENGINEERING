# Acceptance Criteria

- [ ] Fake primary success does not call the fallback
- [ ] Fake primary timeout then fallback success returns the fallback text and two ledger rows
- [ ] Caller error does not call the fallback
- [ ] Stream fixture text matches the joined deltas
- [ ] Cost for a known usage matches the fictional price card
- [ ] Structured helper accepts fenced JSON and rejects a bad schema
- [ ] Context budget rejects an oversized request before any provider is called
- [ ] Default test run needs no API key
- [ ] Design note matches the code, or you updated the note
