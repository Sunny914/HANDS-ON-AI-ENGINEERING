# Architecture Exercise

Write `YOUR_DESIGN.md` before implementation.

1. Problem and constraints, including the ban on keys in git.
2. Modules and the one reason each exists.
3. Interface a provider must satisfy.
4. Data flow for a fallback.
5. Where JSON from a vendor is allowed to appear.
6. Error types and who catches them.
7. Where the price card and timeouts are configured.
8. Which tests inject fakes.
9. What a live adapter must not leak into the router.
10. One trade-off: for example, no automatic prompt compression in this project.

You choose names. The requirements do not list filenames.
