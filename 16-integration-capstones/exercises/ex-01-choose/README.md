# Choose One Capstone

**ID:** `ex-01`
**Stage:** 16-integration-capstones
**Difficulty:** L3
**Category:** Architecture comparison

## Objective

Commit to one system and reject the other two for now.

## Prerequisites

[CONCEPTS.md](../../CONCEPTS.md). Skim the three project READMEs.

## Problem

Write `CHOICE.md`.

## Requirements

Name the option, the user, the first failure you care about, and why the other two options are worse fits for the time you have. List the mandatory stages from the concept table and one stage you will not use.

## Constraints

No application code.

## Inputs and outputs

A note.

## Edge cases

You are tempted to combine all three. The note must refuse that.

## Errors

A choice with no non-goal.

## Acceptance criteria

One option, two rejected options, and a non-goal.

## Testing

Self-review.

## Common mistakes

Choosing A because the course mentioned RAG most often.

## Completion checklist

- [ ] Acceptance criteria pass on code you wrote
- [ ] Required tests exist and you ran them
- [ ] You can explain the design without the hint file

## Reflection

What evidence would make you switch options before milestone 2?

## Extension

Estimate which milestone is the riskiest and why.
