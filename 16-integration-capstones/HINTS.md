# Stage 16 Hints

Stop at the first level that helps. H4 is a review of your code and is not written here.

## ex-01

- **H1:** Pick the problem whose failure mode you want to practice, not the longest document.
- **H2:** Write one sentence for the user, one non-goal, and the option you rejected.
- **H3:** If you want retrieval quality, choose A. If you want approval and audit, choose B. If you want a business workflow that might not need an agent, choose C.

## ex-02

- **H1:** A baseline is callable in a test.
- **H2:** Name the input, the output, the fake, and the one failure. Leave eval and Docker off this slice.
- **H3:** For A, one question and one corpus with a citation check. For B, one propose that does not execute. For C, one valid ticket transition with no model.

## ex-03

- **H1:** A gate is a command that exits non-zero.
- **H2:** List one eval case, one security case, and one trace field. Mark which milestone adds each.
- **H3:** Put the eval case on a frozen file. The security case asserts a ledger or a body that did not change. The trace field is a request id.

## arch-01
