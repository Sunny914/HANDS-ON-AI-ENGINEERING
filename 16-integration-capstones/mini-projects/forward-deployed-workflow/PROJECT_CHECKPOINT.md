# Project Checkpoint

## Definition of done

The acceptance criteria for your bar pass, including the ADR's answer about the agent.

## Rubric

- **Basic:** milestones 1–3. Deterministic queue and one failure.
- **Solid:** through eval and approval, isolation, and traces.
- **Production-oriented:** health, a runbook for CRM down, and a local rollback note.

## Review

1. Show a queue test with no model call.
2. Show a send that required approval.
3. Show CRM down.
4. Read the ADR sentence about agents.
5. Record the test command.

## Extension

A second simulator, such as a status page, still behind a fake. Do not add a research agent.

## Reflection

Which part of this system would get worse if you replaced the queue function with a model?
