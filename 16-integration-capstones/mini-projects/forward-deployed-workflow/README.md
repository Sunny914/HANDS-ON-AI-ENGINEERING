# Capstone C — Forward-Deployed AI Workflow System

A local service that moves a support ticket through a simulated CRM and a simulated mail ledger. Most transitions are deterministic. An agent is allowed only for a bounded draft step, and only if your ADR says the rules cannot do that step.

This option exists so the curriculum is not only retrieval chatbots. You are practicing integration, validation, and the choice not to use an agent.
