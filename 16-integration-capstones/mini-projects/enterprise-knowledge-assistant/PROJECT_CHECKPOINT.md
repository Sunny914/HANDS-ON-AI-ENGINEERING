# Project Checkpoint

## Definition of done

The acceptance criteria for the bar you claim are true in the tests you ran.

## Rubric

- **Basic:** milestones 1–2, happy path and one denial or bad citation.
- **Solid:** milestones 3–7, ADR matches the code, residual risk named.
- **Production-oriented:** milestone 8 plus a rollback note and a smoke command you ran or marked blocked.

## Review

1. Show a same-tenant answer and a cross-tenant denial.
2. Show the split metric case.
3. Show the request id in the trace.
4. Say which stage you left out on purpose.
5. Name the bar and one gap.
6. Record the test command.

## Extension

Hybrid retrieval from Stage 04, still tenant-filtered. Or a third tenant. Do not add a second agent as the extension.
