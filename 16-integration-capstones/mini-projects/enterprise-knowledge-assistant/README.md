# Capstone A — Enterprise Knowledge and Research Assistant

A local API over a small multi-document corpus. Callers ask a question, get an answer with citations, and cannot read another tenant's documents. You measure retrieval and groundedness separately, and you can trace one request.

This is not the Stage 04 project with a new prompt. Stage 04 built the retrieval muscles. Here you integrate tenant boundaries, a regression gate, request traces, and a local service.
