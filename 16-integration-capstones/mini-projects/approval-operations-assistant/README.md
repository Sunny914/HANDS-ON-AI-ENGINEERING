# Capstone B — Approval-Based AI Operations Assistant

A local service where a scripted agent proposes operational actions, and high-risk ones wait for an authorized person. The service stores the pending snapshot, survives a restart, executes once, and can show the audit trail for a request id.

Stage 11 specified the approval rules. This capstone runs them as a service with evaluation cases, traces, and a local deploy story.
