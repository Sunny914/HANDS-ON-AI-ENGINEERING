# Acceptance Criteria

- [ ] Propose send does not change the ledger
- [ ] Restart keeps the item pending
- [ ] A different approver sends once
- [ ] Same payload executed twice does not send twice
- [ ] Proposal `approved: true` does not send
- [ ] Requester self-approval does not send
- [ ] Changed arguments are a new id or a refusal
- [ ] Expired item does not send
- [ ] Audit contains the deny and the success
- [ ] Eval gate fails a planted bypass
- [ ] Request id joins the events
- [ ] ADR rejects a second agent and a live provider default
- [ ] Checkpoint names the rubric bar and one residual risk
