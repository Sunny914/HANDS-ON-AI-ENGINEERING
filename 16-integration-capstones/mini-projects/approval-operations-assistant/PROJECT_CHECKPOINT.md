# Project Checkpoint

## Definition of done

Acceptance items for your claimed bar pass.

## Rubric

- **Basic:** milestones 1–3.
- **Solid:** through the eval gate and audit, with residual risk.
- **Production-oriented:** health, config, and a local rollback story for the service image. Business sends are not "rolled back" except by a new pending action.

## Review

1. Walk propose, restart, approve, one ledger line.
2. Show a bypass that does not send.
3. Show the request id across audit events.
4. Name a risk you did not close.
5. Record the test command.

## Extension

A second high-risk tool with its own schema. Not a second agent.
