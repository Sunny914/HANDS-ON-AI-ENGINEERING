# Stage 16 — Integration Capstones

Choose one capstone and build it in slices. The three options are different systems. They are not three prompts on the same chatbot.

## Options

| Id | Project | Center of gravity |
|----|---------|-------------------|
| A | [Enterprise Knowledge and Research Assistant](./mini-projects/enterprise-knowledge-assistant/README.md) | Retrieval, evidence, evaluation, tenant-safe access, a local API |
| B | [Approval-Based AI Operations Assistant](./mini-projects/approval-operations-assistant/README.md) | Proposals, human approval, audit, recovery, a local API |
| C | [Forward-Deployed AI Workflow System](./mini-projects/forward-deployed-workflow/README.md) | A business workflow over simulated systems, with an agent only where you can justify it |

## Objectives

- Turn a written problem into a baseline you can run offline
- Defend module boundaries and a non-goal list
- Add evaluation, security, observability, and a local deploy story in that order of need
- Say what quality bar you hit: basic, solid, or production-oriented

## Prerequisites

Stages 01 through 15 as they apply to the option you pick. [CONCEPTS.md](./CONCEPTS.md) says which ones are mandatory for each option. [../LEARNING_PROTOCOL.md](../LEARNING_PROTOCOL.md).

## Sequence

[ex-01](./exercises/ex-01-choose/README.md) before any capstone code. [ROADMAP.md](./ROADMAP.md).

## Done

There is no Stage 17. Stopping after a reviewed capstone is a valid end of this curriculum.
