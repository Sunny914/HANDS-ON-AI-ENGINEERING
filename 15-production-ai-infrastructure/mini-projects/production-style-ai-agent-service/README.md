# Production-Style AI Agent Service

A local HTTP service that answers a narrow request with a fake model, calls one authorized tool, records a trace, and can be built into a container. The core suite never needs a paid API.

This is the Stage 15 project. Earlier checklist wording that said "Deploy AI Agent" points here.
