# Research and Analysis Agent

One agent that plans a short investigation, uses approved local tools, remembers only what the write policy allows, and returns an analysis that cites evidence. It must be stricter than the Stage 07 assistant: layers, a budget object, recovery, and an evidence check.

Write the ADR and the orchestration choice before code.
